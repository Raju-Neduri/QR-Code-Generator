# 📱 QR Code Generator

A simple and responsive QR Code Generator web app built with **HTML**, **CSS**, and **JavaScript**. Just enter a URL or any text, and instantly get a QR code that can be scanned by any device!

---

## 🚀 Features

- ✅ Instantly generates QR codes from any text or URL
- 📱 Fully responsive design (works on all screen sizes)
- 🎨 Clean and modern UI
- 🔄 "Generate New QR" button to reset and generate another code
- ⚠️ Input validation with a shaking animation for empty submissions

## 💻 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/Raju-Neduri/QR-Code-Generator.git
   cd qr-code-generator
   ```

2. Open index.html in your browser.

3. Enter any text or URL in the input field and click Generate QR Code.

4. To reset and generate a new QR, click Generate New QR.
